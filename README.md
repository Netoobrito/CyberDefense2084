# Cyber Defense 2084

![Cyber Defense 2084](data/image2.png)

Cyber Defense 2084 is a futuristic arcade defense game developed using Processing and Java.

Enemy drones are attacking the city and you are the last defense robot protecting the base.

Destroy drones before they reach the ground and survive through increasingly difficult levels.

---

# 🎮 Gameplay

The player controls a futuristic defense turret capable of rotating and shooting enemy drones.

As the score increases:

* new levels are unlocked
* enemies become faster
* the difficulty increases

The game features:

* score system
* lives system
* explosions
* sound effects
* victory and game over screens
* progressive difficulty

---

# 🕹 Controls

| Key          | Action        |
| ------------ | ------------- |
| A / D        | Rotate turret |
| LEFT / RIGHT | Rotate turret |
| SPACE        | Shoot         |
| ENTER        | Start game    |
| R            | Restart game  |
